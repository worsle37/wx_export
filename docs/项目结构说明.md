# wx_export 项目结构说明

微信 4.x（`Weixin.exe`）本地聊天记录导出工具 —— 从运行中的微信里取 SQLCipher 密钥 → 解密数据库
→ 按会话导出 Markdown / CSV / HTML。本文件把目录**分类归档**，方便整包克隆或二次开发。

- 交付物：`gui/`（界面程序 + 打包配置）
- 使用与开发说明：[`../gui/README.md`](../gui/README.md)
- 逆向过程与实测结论：[`微信聊天记录导出-技术方案.md`](微信聊天记录导出-技术方案.md)
- 过程脚本清单：[`../scripts/README.md`](../scripts/README.md)

## 2. 交付物：GUI 程序（`gui/`）

| 文件 | 作用 |
|---|---|
| `app.py` | 全部界面代码 + 程序入口；`--cli` 走命令行批量导出，否则开 GUI |
| `wxcore.py` | 业务核心：定位目录、读进程内存取密钥、页级 AES 解密、schema 解析、按会话导出 |
| `微信聊天导出.spec` | PyInstaller 单文件打包（`icon=assets/app.ico`、`console=False`、UPX） |
| `selftest.py` | 开发自检：直接读 `%LOCALAPPDATA%\WxDumpGUI\work`（或 `WXGUI_WORK`）并列会话 |
| `legacy/app_v1_backup.py` | 美化前的旧界面，留档对照 |

### app.py 内部分层

```
入口        run_gui() / run_cli()
主题        C（配色）、F()（字体缓存）、px()（DPI 缩放）
绘图层      _corner_matrix / _corner_photo / rrect —— 纯 Python 超采样圆角贴图（无第三方依赖）
控件层      Card / Btn / Field / Chip / SlimScroll / ConvList / LogView / Toast
业务层      App：数据目录 → ① 取密钥解密 → ② 选会话 → ③ 导出
```

实现要点（改界面时可参考，逐段行号见 `gui/README.md` 的「5.2 代码地图」）：

- **圆角抗锯齿**：Tk 的 Canvas 不抗锯齿。做法是把圆角拆成「直边矩形/线段 + 四角 8×8 超采样贴图」，
  贴图连底色一起烘焙并按 `(半径, 填充色, 描边色, 底色, 翻转)` 缓存，窗口缩放时不重算。
- **不写死卡片高度**：`Card.fit()` 按内容 `reqheight` 收放，避免内容溢出被裁掉（会表现为「下面的圆角变直角」）。
- **线程安全**：耗时任务在工作线程里只 `queue.put()`，所有控件更新都回到 `_poll()` 主线程。
- **DPI**：进程声明 system-DPI-aware，按 `winfo_fpixels('1i')/96` 求缩放系数，全部尺寸经 `px()`。
- **窗口外观**：Win11 深色标题栏 + 圆角 + 同色描边，走 `DwmSetWindowAttribute`（20/19/33/34/35/36）。

## 4. 运行产物与私有数据（**不在仓库里**）

密钥、内存转储、解密库、导出成品这些「跑一遍就能重新生成、但包含真实聊天内容」的东西，
统一放在仓库**同级**目录 `../wx_export_local/`（整理时已迁出，说明见该目录的 `README.txt`）：

| 位置 | 内容 |
|---|---|
| `../wx_export_local/mem/` | `Weixin.exe` 内存转储（含密钥材料与聊天片段），~1.8 GB |
| `../wx_export_local/decrypted/` | 解密后的 36 个 SQLite 明文库，~272 MB |
| `../wx_export_local/out*/` | 历次导出成品（md/csv/html），各 ~21 MB |
| `../wx_export_local/segments/` | 按月切分的文本片段 |
| `../wx_export_local/all_keys.json` | 每库 enc_key —— 等同钥匙，切勿外传 |
| `../wx_export_local/wx_hits*.jsonl`、`*.txt` | 内存命中与分析结果 |

`.gitignore` 对以上全部做了排除；仓库里只有源码与文档。

## 5. 构建 / 复现

```powershell
# 依赖（源码运行时需要；打包成 exe 后不需要）
pip install pycryptodome zstandard pyinstaller

# 直接运行
python gui/app.py

# 用示例数据看界面（不读真实微信）
$env:WXGUI_DEMO="1"; python gui/app.py

# 打包单文件 exe（产物在 dist\微信聊天导出.exe）
python -m PyInstaller gui/微信聊天导出.spec --noconfirm --distpath dist --workpath build
```

打包产物：约 15 MB，单文件、无控制台、自带图标，支持 Win10/11。
运行数据（解密中间件、配置）落在 `%LOCALAPPDATA%\WxDumpGUI\`，不写微信目录。

> 若双击报 `Could not create temporary directory!`：这是 onefile 解压临时目录失败，
> 右键「以管理员身份运行」或把 exe 放到 `D:\Tools\` 一类普通目录再运行即可。

## 6. 关键结论速查

| 项目 | 值 |
|---|---|
| 加密 | SQLCipher 4（WCDB 封装），AES-256-CBC + HMAC-SHA512 |
| KDF | PBKDF2-HMAC-SHA512，256000 次 |
| 页结构 | 4096 字节，保留区 80（IV@4016、HMAC@4032） |
| 密钥形态 | 4.1.11+ 不再明文驻留；`x'<64hex key><32hex salt>'` 经 XOR 掩码存在 `com.Tencent.WCDB.Config.Cipher` 对象里 |
| 取值链 | 字符串地址 → QString/ref 对 → node+0x28 → config_ptr+0x88 → blob(99B) → XOR → 正则 → HMAC 校验 |
| 表名规则 | `Msg_<md5(username)>`；`contact.db` 提供 备注/昵称 → username 映射 |
| 本机实测 | 36 个库全部解密成功（message_0 100.7 MB / 25779 页） |
