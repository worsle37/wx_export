# 使用教程：微信聊天记录导出

> 面向**只想用、不想碰代码**的人。下载一个 exe，点四下，聊天记录就变成 Markdown / CSV / HTML。
> 想改代码、自己打包，看 [`../gui/README.md`](../gui/README.md)。

![界面预览](../gui/preview_dark.png)

---

## 0. 它能做什么

从**你本机正在运行的微信 4.x** 里取出密钥 → 本地解密数据库 → 按会话导出成可读文件。

| 能导出 | 说明 |
|---|---|
| 文字 | 原文，按天分组 |
| 图片 / 语音 / 视频 / 表情 / 文件 | 导出**元信息**（大小、时长、md5、文件名），不含媒体文件本体 |
| 引用回复 | 正文 + 被引用内容 |
| 红包 / 转账 / 位置 / 名片 / 链接 / 小程序 / 视频号 / 聊天记录卡片 | 转成 `[类型] 标题 / 描述` 一行 |
| 系统消息 | `[系统] …` |

**不能做**：不能导出手机端独有的记录（本机没有就导不出）、不能恢复已删除的消息、不能远程读取别人的微信。

全程离线：只读本机文件与微信进程内存，不发任何网络请求。

## 1. 下载

1. 打开仓库的 **Releases** 页面：`https://github.com/worsle37/wx_export/releases`
2. 在最新版本 `v1.0.0` 的 Assets 里下载 **`微信聊天导出.exe`**（约 14 MB，单文件，免安装）
3. 放到一个**普通目录**，例如 `D:\Tools\微信聊天导出\`
   - 不要放在 `C:\Program Files\`、不要放在压缩包里直接双击
   - 桌面也可以，但部分机器 onefile 解包临时目录会失败（见第 8 节）

不需要装 Python、不需要装任何依赖。

> **杀软报毒？** 这类「读进程内存」的工具几乎都会被启发式规则标记。程序只做本地读取，
> 可以加白名单；不放心就自己用源码打包（第 9 节），或直接在源码里审一遍 `wxcore.py`。

## 2. 使用前准备

| 准备项 | 为什么 |
|---|---|
| **微信已登录并保持运行** | 密钥在微信进程内存里，微信退出就取不到 |
| **右键「以管理员身份运行」** | 读别的进程内存需要权限，非管理员可能打不开 |
| 确认电脑上装的是**微信 4.x 桌面版** | 3.x 的库结构不同，不支持 |

**数据目录在哪？** 一般在：

```
C:\wechat_data\xwechat_files\wxid_xxxxxxxx\db_storage
```

不确定就先不管，程序启动时会自动检测（读 `%APPDATA%\Tencent\xwechat\config\*.ini`）；
多账号会有多个 `wxid_*` 目录，选当前在用的那个。

## 3. 四步上手

### 第 1 步：确认数据目录

打开程序，看「微信数据目录」这一栏：

- 已经自动填好 → 直接下一步
- 空的或填错 → 点 **自动检测**；还不行点 **浏览…**，手动选到 `db_storage` 这一层（不是它的上级）

### 第 2 步：读取密钥并解密

点右上角 **① 读取密钥并解密**。

- 首次大约 **1～3 分钟**（扫内存 + 解密 `message_*` / `contact` / `session`）
- 期间三个按钮会变灰、底部有一条蓝色进度线在跑，右侧日志逐行输出：
  ```
  [*] 数据目录：C:\wechat_data\xwechat_files\wxid_xxxx\db_storage
  [*] 发现 36 个库，其中加密 36 个
  [*] 开始解密需要的库（message_* / contact / session）…
  [+] 完成，共 N 个有消息的会话
  ```
- 看到 `[+] 完成` 就绪，会话列表会填满

**失败怎么办**：看第 8 节。最常见就是「微信没开」或「没给管理员权限」。

### 第 3 步：选会话

- 上方搜索框输入 **备注 / 昵称 / wxid** 都能过滤，边打边筛
- 单击选中；`Ctrl+单击` 加减选；`Shift+单击` 连选；`Ctrl+A` 全选（先点一下列表）
- 右侧计数会显示「显示 x / 共 M 个会话」，底部状态栏显示「已选 N 个会话」

### 第 4 步：选格式 → 导出

1. 「输出目录」默认是 `桌面\微信导出`，可以改（点 **浏览…**）
2. 「导出格式」三枚胶囊：**MD / CSV / HTML**，默认全开；至少留一个
3. 点 **② 导出选中** → 完成后自动弹出输出目录
4. 想一次导全部：点 **导出全部**（不受搜索过滤影响，导的是所有会话）

> 双击列表里某一行 = 只导出那一个会话。

## 4. 界面速查

| 位置 | 控件 | 作用 |
|---|---|---|
| 顶部 | `① 读取密钥并解密` | 取密钥 + 解密 + 载入会话列表 |

## 5. 导出结果长什么样

文件名 = 会话名清洗后（非「字母/数字/下划线/中文」→ `_`，截断 60 字）+ 扩展名，例如
`这个年纪怎么睡得着的_.md`。同一会话重复导出会覆盖同名文件。

### MD（推荐直接看）

```markdown
# 会话名

- 消息数：1284
- 时间范围：2024-09-10 12:17 ~ 2026-03-31 23:58

---

### 2024-09-10

**12:17 对方**：在吗

**12:18 我**：在
```

### CSV（推荐丢进 Excel / 做统计）

表头 `时间,发送者,类型,内容`，UTF-8 带 BOM，Excel 双击不乱码；`类型` 是微信内部数值。

### HTML（推荐分享 / 存档）

单文件、深色主题、按天分组，`时间 / 发送者 / 内容` 三栏，双击浏览器直接看。

## 6. 进阶：命令行批量导出

```powershell
# 导出全部会话
.\微信聊天导出.exe --cli --all --out D:\导出

# 按名字导（备注 / 昵称 / wxid 都能匹配）
.\微信聊天导出.exe --cli --name "张三" --out D:\导出

# 直接给表名
.\微信聊天导出.exe --cli --table Msg_<md5(username)> --out D:\导出

# 复用上次解密的数据，不重新取密钥（快）
.\微信聊天导出.exe --cli --no-reextract --name "张三" --out D:\导出
```

| 参数 | 说明 |
|---|---|
| `--cli` | 走命令行模式 |
| `--dir` | `db_storage` 目录，缺省自动检测 |
| `--out` | 输出目录，缺省 `桌面\微信导出` |
| `--name` / `--table` / `--all` | 选会话；都没给会列出前 15 个会话 |
| `--no-reextract` | 复用已解密数据 |

> exe 是**窗口程序、没有控制台**，所以命令行模式建议用源码跑 `python app.py --cli …`，
> 或者把 exe 的输出重定向到文件。命令行固定导出 md+csv+html 三种格式。

## 7. 数据放在哪 / 怎么清理

| 路径 | 内容 |
|---|---|
| `%LOCALAPPDATA%\WxDumpGUI\work\` | 解密后的中间数据库（可随时删，删了下次重新解密） |
| `%LOCALAPPDATA%\WxDumpGUI\config.json` | 上次的目录、窗口大小位置 |
| 你指定的输出目录 | 导出的 md / csv / html |

**不写微信自己的数据目录**，不改微信任何文件。

**卸载**：删掉 exe，再删 `%LOCALAPPDATA%\WxDumpGUI\` 即可，注册表不留东西。

## 8. 常见问题

**Q：点「读取密钥」提示失败 / 一直没动静？**
1. 确认微信已登录、窗口开着（不是只留后台托盘）
2. 右键「以管理员身份运行」
3. 微信刚大版本升级过（4.1.x → 4.2.x 这类）对象结构可能变了，需要等适配
4. 看日志里有没有 `[!] 打不开 PID=…（权限不足？试管理员）`

**Q：列表是空的 / 少了某个会话？**
- 该会话本地确实没有消息（从未聊过、只在手机端）
- 或者你看到的是**上次解密的旧数据**：日志里出现「这次没取到密钥，尝试复用上次已解密的数据…」时，
  删掉 `%LOCALAPPDATA%\WxDumpGUI\work\` 再点一次「① 读取密钥并解密」

**Q：图片 / 语音为什么没有文件？**
媒体本体是另一套 AES key 加密的，本工具只导消息文本 + 媒体元信息（大小 / 时长 / md5）。

**Q：导出很慢？**
条数多（上万条）时会慢，正常。日志里每个会话会打 `[+] 名称：N 条 → 文件名`。

**Q：双击报 `Could not create temporary directory!`？**
onefile 程序解包临时目录失败：换到 `D:\Tools\` 一类普通目录，或以管理员身份运行。

**Q：界面字太大 / 太小？**
按系统 DPI 自动缩放（100%–200%），拖窗口边缘可放大，尺寸会记住。

**Q：换账号 / 重装微信后要重新弄吗？**
要。密钥跟账号绑定，换账号请先点一次「① 读取密钥并解密」。

## 9. 自己从源码打包（开发者）

```powershell
pip install pycryptodome zstandard pyinstaller
cd gui
python -m PyInstaller 微信聊天导出.spec --noconfirm --distpath ..\dist --workpath ..\build
# 产物：dist\微信聊天导出.exe（单文件、无控制台、内置图标）
```

源码结构：

```
gui/app.py      界面 + 入口（GUI / --cli）
gui/wxcore.py   取密钥 / 解密 / 解析 / 导出
gui/微信聊天导出.spec   PyInstaller 配置
```

先在源码里跑一遍：

```powershell
python gui/app.py                      # 真实模式
$env:WXGUI_DEMO="1"; python gui/app.py # 演示模式（假数据，不读微信，用来调界面）
```

- 导出的 md / csv / html 是**明文聊天记录**，转发前想清楚发给了谁
- `%LOCALAPPDATA%\WxDumpGUI\work\` 里是解密后的完整数据库，等同原始聊天记录
